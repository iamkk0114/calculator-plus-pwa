# Calculator Plus PWA (計算機加強版 - 無廣告純淨版)

還原 Google Play 經典 **Calculator Plus (Digitalchemy)** 介面配置與功能的 Progressive Web App (PWA)，支援直接安裝至 Android / iOS 手機主畫面與離線使用。

## 功能特色
- **原版視覺與操作體驗**：淺天藍顯示幕、亮藍色括號/函數高亮、智慧括號 ()、即時預覽列與琥珀橘 = 鍵。
- **四大完整分頁**：
  1. **Calculator**：標準 5×4 大按鍵佈局。
  2. **Scientific**：7×6 科學計算機（含 MC / M+ / M- / MR、2nd、DEG/RAD、三角與對數函數）。
  3. **Currency**：多國貨幣即時算式換算（支援邊打算式如 5 + 7 + 12 邊換算）。
  4. **Units**：長度、面積、體積、質量、溫度單位轉換（含 ⇅ 快速上下互換）。
- **歷史紀錄抽屜 (紀錄)**：依「今天 / 昨天」自動分組，支援單筆 ⋮ 選單（全部複製、僅複製結果、分享、刪除）。
- **100% 離線可用**：內建 Service Worker 與 localStorage 持久化，關閉重開自動還原算式與記憶值。
